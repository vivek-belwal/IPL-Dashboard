# 🏏 IPL Analysis Dashboard

## 📊 Overview

An interactive **Indian Premier League (IPL) Analysis Dashboard** created using **Microsoft Excel** to analyze IPL match data and present key insights through interactive charts, graphs, KPIs, and filters.

## 🎯 Objectives

* Analyze IPL data from **2008–2024**.
* Compare team performance.
* Analyze toss decisions and winning percentage.
* Identify top IPL venues.
* Analyze IPL title winners.
* Identify top **Man of the Match (MoM)** award winners.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Slicers & Filters

## 📈 Dashboard Visualizations

* **KPI Cards** – Season, Winner, Runner Up, Player of the Series
* **Stacked Column Chart** – Team wins based on batting first vs fielding first
* **Doughnut Chart** – Toss decision-based winning percentage
* **Horizontal Bar Chart** – Top 10 venues with most matches
* **Treemap Chart** – IPL title winners

## 🔍 Key Insights

The dashboard provides insights into:

* Team-wise winning performance
* Batting first vs fielding first results
* Toss decision impact
* Venue-wise match statistics
* IPL championship history
* Top-performing players

1. Download `IPL_Dashboard.xlsx`.
